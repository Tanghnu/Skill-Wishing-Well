# Skill许愿池 · Skill-Wishing-Well

把“我希望有一种能力能解决这个困扰”，转化为可检查的需求、合适的技能方案和实际交付。

Skill许愿池是供 AI 编程助手读取的指令型技能，帮助助手先理解问题，再判断应该复用、组合、改造、新建技能，还是直接完成一次性任务。

- 版本：`1.0.1`
- 技能标识：`skill-wishing-well`
- Codex 显示名：**Skill许愿池**
- 独立社区项目，非 OpenAI 官方产品；所提及的第三方项目不代表为本项目背书。

## 适用场景

- 不知道有没有现成技能能解决某个反复出现的问题。
- 想比较几个技能的实际适配程度、依赖和限制。
- 希望把已明确的重复工作固化为可复用技能。
- 已有技能不合适，需要组合或改造，并验证结果。

普通问答和一次性任务不会自动被转化为技能建设。寻找与比较请求也不会自动授权安装、覆盖或发布。

## 安装到 Codex

1. 下载并解压仓库或版本压缩包。
2. 将其中整个 `skill-wishing-well` 文件夹复制到 `~/.codex/skills/`。Windows 通常为 `C:\Users\你的用户名\.codex\skills\`；如设置了 `CODEX_HOME`，则使用其下的 `skills` 目录。
3. 重新打开 Codex 或新建聊天，查找“Skill许愿池”。

最终目录应为：

```text
~/.codex/skills/skill-wishing-well/SKILL.md
```

若已有同名目录，先备份再替换。旧版内部名称为 `skill-forge`；升级时将旧目录移到技能目录外备份，避免重复加载。不要把整个仓库目录作为技能目录安装。

此安装方式已在开发者本机验证；不同宿主或版本的发现路径可能不同。其他支持 Agent Skills 的助手需按其自身说明安装，尚未验证兼容性。

## 使用示例

**寻找能力：**

> 使用 $skill-wishing-well 分析我的困扰：我每周都要整理很多客户材料，请帮我寻找合适能力并提出方案，暂不安装。

**比较技能：**

> 使用 $skill-wishing-well 比较我提供的两个技能，核对来源、依赖和任务覆盖，并推荐适合我的一个。

**构建技能：**

> 使用 $skill-wishing-well 把“从会议记录提取负责人、期限和原文证据”做成可复用技能，完成构建和验证，先不要安装。

助手会结合上下文提出验收标准，检查已有能力，并说明实际验证范围。需要安装时，请另外明确提出安装请求。

## 依赖与限制

本包只有 Markdown 和 YAML，无可执行脚本、额外运行库或内置 API Key。需要能读取技能文件的 AI 助手；联网发现、仓库读取、文件写入等能力取决于宿主提供的工具及权限。宿主服务或后续选用的第三方服务可能另行收费。

技能不提供搜索服务，也不保证找到所有候选。没有网络时可以分析本地或已提供材料。结构检查和有限任务演练不能证明所有任务的效果；尚未完成跨设备、跨宿主验证，也未证明相对普通助手的普遍性能优势。

请勿在公开 issue 中提交密钥、客户材料或其他敏感信息。使用第三方技能前仍需核对其许可与实际行为。
